The DBLP Bibliography, which is maintained by Michael Ley, is a valuable tool for database research. This DVD contains the latest version of the DBL-browser (Digital Bibliographic Library Browser) (as of February 2006). The DBL-browser is a utility for browsing DBLP offline.
  • Goto the DBP Browser on this DVD (link present on DVD only, please use the on-line version).
  • The DBL-Browser homepage: http://dbis.uni-trier.de/DBL-Browser/
