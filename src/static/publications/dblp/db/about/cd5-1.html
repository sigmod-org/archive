The ACM SIGMOD Anthology, Volume 5, Issue 1:
SSD, DPD, SIGIR Forum, ...

This CD contains the scanned text of
  • The Symposium on Large Spatial Databases (SSD) 1989-1999,
  • Distributed and Parallel Databases 1993-1999,
  • ACM SIGIR Forum 1971-1999,
  • The ACM Transactions on Database Systems (TODS) 1999 issues 3 & 4,
  • The XP Workshops on Database Theory 1980, 1981, 1983, and 1986,
  • System R Papers
  • Collected Works of E. F. Codd
  • Collected Works of Jim Gray
  • TSQL2 Temporal Query Language and the TSQL2 Book
  • The Ingres Papers Book
  • Database Design by Gio Wiederhold
  • Logics for Databases and Information Systems
  • SQL Papers

To locate a paper you may browse the tables of contents, use the Acroread full text index, or employ DBLP. To read/print the papers you have to install the Adobe Acrobat® Reader.
