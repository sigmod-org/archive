System R People

based the System R People Page by Paul R. McJones
  • Michel E. Adiba (1979-1980): designs for R* snapshots, derived relations, distributed catalog. <Michel.Adiba@imag.fr>
  • Mike W. Blasgen: RSS index component, manager of RSS, manager of System R. <michael@blasgen.com>
  • Donald D. Chamberlin: manager of RDS, co-designer of SQL. <chamberlin@almaden.ibm.com>
  • David M. Choy: Fast loader, reorg utility, runstat, catalog. <dmc@almaden.ibm.com>
  • Ronald Fagin: authorization, indexing, and theory (including normalization). <fagin@almaden.ibm.com>
  • Jim Gray: IBM: RSS transaction component; SQL/DS consulting, SQL/DS, DB2, IMS Fast Path efforts; Tandem: NonStop SQL; FastSort, and Pathmaker; DEC: Rdb, TP and AlphaSort; Microsoft: NTclusters. <gray@microsoft.com>
  • Donald J. Haderle: DB2 (1978-): chief architect, IBM Fellow, architecture and development of IBM's other relational database managers and related products. <dhaderle@vnet.ibm.com>
  • Theo Härder (1976): RSS sort/merge component. <haerder@informatik.uni-kl.de>
  • Bob Jolls: manager of SQL/DS at Santa Teresa; manager of VS/QUERY (QMF); manager of DB2 (1980-1981). <Bobjolls@aol.com>
  • W. Frank King III: manager of System R. <king@concero.com>
  • Bruce G. Lindsay: RSS storage pools; R* architect. <bgl@almaden.ibm.com>
  • Guy M. Lohman (1982-): R* optimizer. <lohman@almaden.ibm.com>
  • Raymond A. Lorie: XRM; RSS: buffer management, shadow pages, transaction management; RDS: compilation of SQL, optimization. <lorie@almaden.ibm.com>
  • Paul R. McJones (1975-1976): RSS crash recovery; author of the System R web site. <paul.mcjones@acm.org>
  • James W. Mehl: System R: SQL parser, MVS port, Boeing joint study contact. <JimMehl@acm.org>
  • Roger L. Miller (1979-): DB2: lead strategist, planning, and development (SQL, languages, install, security, audit, standards, performance, concurrency, and availability). <millerrl@us.ibm.com>
  • C. Mohan (1981-): R* transaction management, ARIES, DB2, MQSeries and Lotus Domino recovery and locking. <mohan@almaden.ibm.com>
  • John Nauman: DB2 development manager. <john@johnnauman.com>
  • Thomas G. Price: RSS: buffer manager, latches, alternate (never-implemented) recovery manager design that didn't use shadow pages; RDS: optimizer. <tom.price@ieee.org>
  • Gianfranco R. Putzolu: RSS record component, Technology Evaluation (IBM DB2 prototype); Tandem NonStop SQL. <fputzolu@us.oracle.com>
  • Mario Schkolnick: RDS optimizer, database design tools. <schkol@schkol.engr.sgi.com>
  • Patricia G. Selinger: RDS optimizer, precompiler, authorization; R* optimizer and compiler. <pgs@us.ibm.com>
  • Donald R. Slutz: RDS; Esvel; Tandem NonStop SQL. <dslutz@microsoft.com>
  • Paolo Tiberio: (1978-1979, 1981): Update cost evaluation, System R-based database design tool. <paolo.tiberio@unimo.it>
  • Irving L. Traiger: manager of RSS component of System R. <traigerik@worldnet.att.net>
  • Bradford W. Wade: RDS: authorization, code generator, catalog creation, performance, UFI, installation procedures. <bwade@almaden.ibm.com>
