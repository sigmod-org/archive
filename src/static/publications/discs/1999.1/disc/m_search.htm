Search DiSC'99

Three search mechanisms are avaiable on DiSC'99:

HTML Search
PDF Search
Author Index

HTML Search

Use the following applet to search through any of the HTML pages included in DiSC'99. (This utility requires a Java-capable browser; Netscape Navigator 4.0+, or Microsoft Internet Explorer 4.0+ recommended.) Enter one or more keywords below and select find. Query results will be displayed in a list, from which you can select individual pages. Selecting the new win option will present your selection in a new window.


PDF Search

This CD-ROM provides a full text index for those papers included in DiSC'99. The index is based on text extracted from the scanned paper images using optical character recognition (OCR) techniques. The accuracy of the text extraction process is limited in some cases by the quality of the original typescript; this can also affect the quality of text that can be selected using the Acrobat text selection tool.

You can utilize the full text index with Adobe Acrobat Reader 3.01+ With Search, which can be found under the install directory of the ACM SIGMOD Anthology CD #3, or online at Adobe's Acrobat Web Site. Once within Acrobat Reader, select tools/Search/Indexes from the menu, then Add. Select the file Disc99.pdx from the root directory of DiSC'99 CD#1.

To search for specific words of phrases, select Tools/Search/Query, and enter your keywords in the dialog box.

For additional information on performing full text searches, choose the Help/Plug-In Help/Using Acrobat Search menu entry for complete details.
 
 

Author Index

Also available on DiSC'99 is an index of all SIGMOD'98, PODS'98, and VLDB'98 authors, along with their contributions. The Author Index can be selected at any time from the menu to the left.
