Expect and Tolerate Failures

  • Software is NOT stable

  • Hardware fails every week (at this scale)

    • this is < 99.9%

    Focus on graceful degradation

    • Node loss causes linear degradation in database size (random records removed)
    • DB size * queries/sec ~ constant
      => We can reduce tradeoff DB size during surges
