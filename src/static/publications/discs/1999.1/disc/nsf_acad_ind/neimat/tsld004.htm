Application Tier

  • Flurry of activity be it for ERP applications, SCM applications, or Web application servers

  • Difficult data management / data access problems being addressed by many ad-hoc solutions. Many of these problems revolve around:

    • Reducing number of trips to the database server
    • Offloading the database server
    • Mapping of business objects to relational model
    • Load balancing between multiple application servers
      • managing consistency of data among multiple copies
