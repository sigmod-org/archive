  • Object to relational mappers:

    • Persistence
      • Map C++ or Java to SQL
      • Live object cache:
        • shared among multiple applications,
        • updates are private until committed,
        • commit executed against DBMS server and propagated to shared cache
        • registered clients notified that shared cache was modified
      • Navigational access to cached objects through programming language, declarative access to data on DBMS server through SQL.
