Some of the Solutions, cont.

  • Oracle8 Client-Side Object Cache

    • Object cache for object-relational DBMS
    • One cache per context -- i.e., caches are not shared among applications running against the same server.
    • Declarative (through SQL) as well as navigational access to cached objects
    • Application must maintain consistency of the cache:
      • Explicit flagging of modified objects by application
      • Explicit flushing of cache to server by application
      • Explicit refresh of cache
