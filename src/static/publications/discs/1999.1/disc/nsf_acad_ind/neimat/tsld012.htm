Common Thread

  • Main-memory data management in the application server to improve performance by:

    • reducing the number of trips to the DBMS server
    • reducing the load on the DBSM server
    • providing the performance benefits of main-memory data management

  • But € there is no agreement on:

    • API / data model
    • Division of labor between DBMS server and application server
    • Consistency model

  • Solutions are incomplete, leave much to the application, and are often not coordinated with the DBMS
