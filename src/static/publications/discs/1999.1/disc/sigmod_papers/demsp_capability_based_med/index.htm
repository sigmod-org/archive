Capability Based Mediation in TSIMMIS
  • The SIGMOD-98 demo of the TSIMMIS project is based on the paper: SIGMOD-98 Paper (PostScript version).


    • In this paper, we describe how source capabilities expressed as wrapper templates are used by the TSIMMIS mediators to generate feasible query plans.

  • Presentation Slides: SIGMOD-98 Slides.


    • The presentation shows the basic TSIMMIS architecture involving a network of mediators and wrappers. It illustrates the problem of capability-based mediation through an example and then sketches the solution implemented by the TSIMMIS system to provide capability-based mediation. The latter part of the presentation has a detailed example with source specifications, mediator view definitions, a user query, the logical and physical query plans.

  • The demo given at SIGMOD-98 is available online at: SIGMOD-98 demo.


    • The demo uses the same example as the slides and shows how the TSIMMIS mediator generates source capability sensitive query plans for user queries in the example domain.

  • More information about the TSIMMIS project is available at: TSIMMIS home page.


    • Source code for the TSIMMIS wrappers and mediators, as well as TSIMMIS related publications can be downloaded from there.
