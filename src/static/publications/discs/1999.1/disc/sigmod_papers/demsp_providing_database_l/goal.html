The Goal of WHIRL
  • Access data-like pages on the Web as if they were data, not hypertext.
    • Answer non-trivial queries within a site.
    • Join with other data-like pages from other sites.

  • A major problem: Many information sources on the web contain "messy" data - and data cleaning is expensive.

    Specifically, sources often contain no global values that can be used as keys (such as tickertape symbols); also different sources can use different names for the name external entity.

  • Examples:
    • Information about children's software (mirrored version)
    • Publishers of children's software (page 1, page 2)
    • Notice the variant names for publishers like Microsoft (Microsoft Kids vs Scholastic/Microsoft)
