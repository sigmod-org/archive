RasDaMan Demonstration

The RasDaMan project is a multidimensional database aimed at the management of large MDD objects. MDD stands for "Multidimensional Discrete Data", meaning data of arbitrary dimensionality where each cell is the same size. The RasDaMan server uses a conventional DBMS for linear BLOB storage (currently O2, ports to RDBMS planned). MDD objects can be stored using arbitrary tiling to improve performance.
