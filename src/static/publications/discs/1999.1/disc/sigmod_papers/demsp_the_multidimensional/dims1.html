Arbitrary dimensions

RasDaMan can handle data with any kind of dimensionality. It is not limited to two, although most of the examples on these pages are two-dimensional images. Due to this freedom in dimensionality RasDaMan can be used for storing data from a wide range of applications, e.g. audio samples (1D), images (2D), movies and tomograms (3D) as well as high-dimensional, abstract data as used in OLAP data cubes.

For an example of 1D data we'll have a look at a projection to y=250 of the following Digital Elevation Map of the Grand Canyon. The horizontal line signifies which part of the image is affected by the projection.

The following query makes the server perform the projection to a 1D object which will then be sent to the client: 

SELECT img[*,*, 250]
FROM   rockies AS img
For more about the trimming operator "[ ... ]" click here. Alternatively you could download the entire image and make RasDaView do the projection; in this case, however, RasDaView was only used to display the data as a bar chart. Note how light areas in the image correspond to peaks and dark areas to valleys in the bar chart.
