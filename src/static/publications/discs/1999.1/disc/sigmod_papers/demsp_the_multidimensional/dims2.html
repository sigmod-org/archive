Arbitrary dimensions, continued

For demonstrating 3D objects we chose a tomogram scan with the domain [0:255, 0:255, 0:153]. Since a computer screen is a 2D object, visualising data with more than 2 dimensions calls for projections. In this example RasDaView downloaded the entire 3D datacube and then displayed its contents using simple orthogonal projections which would be described as [dom_1, dom_2, dom_3] using RasDL's trimming operator, where exactly one of the dom_i is a single number which determines the position of the plane to project to and the other two domain descriptors are "*:*".

Here are thumbnails of three projections along different axes of the data cube. The leftmost image was created using RasDaView's equivalent of the [*:*, *:*, 75] operator, the middle image using the equivalent of [*:*, 90, *:*] and the rightmost one using the equivalent of [128, *:*, *:*].
