Overview:
the agent pool

[Back to Architecture]

The Agent Pool offers a large range of services that can be used by the other components of the system (Dispatcher, View Factory, Database, Output-Formatter).

  • Information Retrieval services
    • IR query generation (to send parametrized queries to search engines)
    • Wrappers (to directly access databases available on the Web)
  • Information Extraction services

    •  
  • "Fuzzy matching" services
    • attribute matching
    • method matching
  • Formatting/Display services
    • HTML formatting
    • DHTML formatting
    • Document Display
    • Span display
