We are sorry not to provide the presentation with the demonstration given at SIGMOD'98 but only a simulation. Nevertheless, the following scenario illustrates the different steps of the process.
 

The Scenario

Before any query is asked, the cache is empty: there is no predefined schema in the database, and thus no data either. You are the user and you are using AKIRA to get information about upcoming conferences. You will ask three queries:
  • Query 1:"What are the upcoming conferences (with their submission deadline and location)?"
  • Query 2:"From the retrieved ones, what are the ones that are organized in 1998?"
  • Query 3:"What are the conferences (with their dates and location) where Abiteboul is a PC member?"
