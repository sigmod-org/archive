Overview:
the output-formatter

[Back to Architecture]

The query language provided by AKIRA is a restricted subset of OQL and does not offer sorting or aggregate features. Today, the result can be returned as:

  • plain-text
  • HTML
  • Dynamic HTML
  • MSA
The last 2 options are not supported by all browsers.

Unfortunately, the current implementation only proposes a glimpse of what should be offered. In the future, the result could be also returned as XML or as any data-format provided by the user.
