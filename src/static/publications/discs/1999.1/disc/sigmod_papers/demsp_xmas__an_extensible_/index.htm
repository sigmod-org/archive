Mobile Communication Simulation

Demo Description

Demo Preview

  Instruction

Click the Image
  1. To run demo, please click the left image.  It takes dozens of seconds until the demo window shows. 
  2. In the demo window, you can see one map and two graphs. The map shows the movements and call setups of mobile stations. The right-below graph shows the number of messages per second processed at the home location register. The right-above graph shows the number of database operations performed at the home location register to process these messages. 
  3. The map has two view modes, "View Mobile Stations" and "View Statistics". 
    • To change current view mode, please select radio buttons in the "View Mode" area below the map. 
    • "REGNOT" below the map represents the percentage of REGNOT message occurrence in this simulation. (currently fixed by 5%) 
  4. Each graph has two graph types to display: bar graph and line graph. 
    • To change graph type, please select radio buttons in the "Graph Type" area. 
  5. Each graph has a scale slider at its right side. 
    • To change the graph scale, please move the thumb on the slider in the "Max Value" area. 

Performance of Xmas Prototype

Demo Description

Demo Preview

  Instruction

Click the Image
  1. To run demo, please click the left image.  It takes dozens of seconds until the demo window shows. 
  2. In the demo window, you can see two graphs, each of which shows lookup and update performance respectively. 
      3. To get performance data, 
    • Please click the "Refresh" button on each graph. 
    • Please wait until performance data show in the graph area. This takes about 15 ~ 20 seconds. 
  3. Each graph has two graph types to display: bar graph and line graph. 
    • To change graph type, please select radio buttons in the "Graph Type" area. 
  4. Each graph has a scale slider at its right side. 
    • To change the graph scale, please move the thumb on the slider in the "Max Value" area.
