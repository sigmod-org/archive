Bank of America Case Study: The Information Currency Advantage
Felipe Carino, Mark Jahnke
Full Paper (PDF)

Abstract
This paper describes the external forces that motivate financial institutions to collect, aggregate, analyze, and mine data so that it can be transformed into information, one of a financial institution's most valuable assets. In this paper we refer to this strategic information asset as "informationcurrency." In general, we describe the state of banking and the rapid global changes that affect financial institutions. We analyze how Bank of America (BofA) created and employed its informationcurrency using the Teradata TMRelational Database Management System (Teradata RDBMS). The Teradata RDBMS manages a very large data warehouse (NCR Scalable Data Warehouse) for BofA using an NCR WorldMark TM 51OOM MPP (Massive Parallel Processing) platform [Wck93].
