Sample Session

The queries for the mentioned applications are predefined in an XML-based format (example (do not be afraid of the XML-code ;-)). This plan description is parsed by a servlet, which extracts information about the parameters, which has to be provided by the user and shows an appropriately generated html-form in the browser of the user.

After the user has provided the necessary information and the "start query" button has been hit, the servlet passes the description of the query together with the user-specified parameters to a query server (this means, the query is passed to a cycle provider). After its computation, the result of the query is sent to the servlet, which constructs the according html page.
