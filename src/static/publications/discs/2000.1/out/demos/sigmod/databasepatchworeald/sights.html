Find sights for a specific city

Data Transformation

Here we demonstrate the potential of dynamic function loading in the scope of data transformation.
  • The first query gets information about sights at a specific city in Germany. A picture of the respective sight is embedded in the query result.
    The according SQL query: 
    select city, sight, picture
from   sights
where  city = :cityParam;

    Initiate query, Initiate query (online)

  • The second query computes the same result but the images can be scaled.
    The according (notional) SQL query: 
    select city, sight, scale(picture)
from   sights
where  city = :cityParam;

Move Functions to the Data

New functions can be incorporated at any cycle provider. This can lead to a reduction of network traffic. Unfortunately we do not have access to a server with a better network connection to the data source than our servers in Passau have. During the SIGMOD demonstration we had an additional server at the conference site and used a server in Passau to access the data source in a faster way.
