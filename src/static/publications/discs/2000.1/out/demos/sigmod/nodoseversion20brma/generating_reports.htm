Generating reports

Nodose provides a variety of ways to output data extracted from files:

  • XML
  • Tabular
  • ODL
  • OEM

Additional formats can be added by writing custom code.

XML

To output the data in XML, choose "XML Export..." from the Results->Exports menu. The following dialog will appear:



The first two checkboxes control whether the data from only the currently selected file or all files in the document class will be output. If data from multiple files is output, the second checkbox controls whether the data is written into a single file or one output file per input file.

The final three checkboxes control the extra attributes Nodose per element. If "Generate filename attributes" is checked, an attribute called "filename" will be generated for each element that is set to the name of the file the data was extracted from. If "Generate offset attributes" is checked, attributes called "startOffset" and "endOffset" will be generated for each element that specifies where in the input file it came from. Finally, if "Generate confidence attributes" is checked, an attribute called "confidence" will be generated for each element which contains a value between 0 and 1 indicating how confident Nodose is in the correctness of the extracted data.

Tabular

The text exported allows a list of records to be output. The format of each row can be customized before the data is generated. To output tabular data, select a list of records in a document and then choose "Text Export..." from the Results->Exports menu. The following dialog will appear:



The tree view shows the record and all of its fields. Clicking on a field adds it to the row schema. The default format for the output file is comma separated but the separator can be changed by the radio buttons in the bottom left of the dialog box. For more control, the actual format of the line can be edited. To do so, click the "Edit Row Schema" checkbox and then edit the row schema text field. Any characters can be used in the schema line except for '<' and '>' which are used to delimit fields. If these characters are required in the output file, choose"Options" from the "View" menu and change the delimiter characters.

If the "Encapsulate Text" checkbox is checked, the data from text fields will be output surrounded by the text qualifier character which defaults to a quote. The default can be changed by editing the "Text Qualifier" field.

To preview the output before it is generated, select "Sample" from the "View" menu.

ODL

To output the types in the document class in ODL, choose "ODL Report" from the Results->Reports menu. A window will appear with the ODL which can be saved using the File menu.

OEM

To output data in OEM, choose "OEM Report" from the Results->Reports menu. The following dialog will appear:


The dialog has two tabs that control whether the data from only the currently selected file or all files in the document class will be output. If all of the files are to be output, the dialog allows all of the output to be merged into a single file or output as separate files. There are also options to control how many and what types of entry points are created. It is also possible to output only the data from the currently selected file.
