Menus

File

  • Open File... - Opens and adds a new file to the document class.
  • Remove File - Removes an existing file from the document class.
  • Open Class - Opens an existing document class.
  • Save Class - Saves the current document class.
  • Save Class As... - Saves the current document class under a new name.
  • Close Class - Closes the current document class.
  • Exit - Exits the program.

Edit

Not used in this release.

Structure

  • Add Node - Adds the currently highlighted text as a substructure of the selected node. The new node will be a string until changed.
  • Delete Node - Deletes the currently selected node. Any subtrees are made children of its parent.
  • Delete Children - Deletes all of the subtrees rooted at the currently selected node.
  • Delete Subtree - Deletes the selected node and all of its descendents.
  • Delete Remaining Elements - Deletes all the nodes below the currently selected one that have the same parent.
  • Expand All - Expand the entire tree below the selected node.

Mine

  • Mine - Run the currently selected miner on all nodes of the same type as the currently selected node.
  • Mine Recursive - Run the currently selected miner on all nodes of the same type as the currently selected node. If any new nodes are added as a result, run the miner on those nodes as well. Continue until no new nodes are added.
  • Options - Opens the miner specific options dialog.
  • Analyze - Analyze the current files for mining errors.
  • Configure Analyzer - Opens the analyzer specific configuration dialog.

Results

  • Reports - All of the available reporters are listed as a submenu.
  • Exports - All of the available exporters are listed as a submenu.

Tools

  • Manage Types - Opens the type manager tool.
  • Type Mapper - Opens the schema mapping wizard.
  • Import DTD - Opens the XML import wizard to import the type structure defined by an XML DTD into Nodose.

Windows

This menu lists all of the open files to allow rapid switching between them.

Help

  • About... - Displays information about the current version of Nodose.
