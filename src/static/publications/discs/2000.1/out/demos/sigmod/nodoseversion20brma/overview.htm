Overview

Nodose is a tool for extracting data from text files (including web pages). The extracted data can be output in many different formats including XML. Nodose also performs schema translation in case the format of the source files is different from the desired format of the report.


Nodose has the following features:

  • No programming is required - Nodose is trained to extract data entirely by example using a GUI.
  • Analysis of extracted data - Extracted data is analyzed for correctness so that errors in the learned algorithms can be caught before invalid data is used.
  • Schema translation - The extracted data can be translated into a different format before reporting. No programming is required.

The current version of Nodose can be found at http://www.cs.nwu.edu/~adelberg/nodose/nodose.html.
