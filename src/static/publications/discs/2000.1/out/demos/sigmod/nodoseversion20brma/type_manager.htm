Type Manager

The Type Manager is a tool for creating or modifying a type hierarchy. It can be used to define or delete types, create or modify a type hierarchy, set characteristics of a type and view statistics about a type.


Type List

This list shows all of the types currently within the hierarchy, in alphabetical order. When the user selects a type in the list, the toolbar, ancestor list, child list and statistics are updated to be specific to the selected type.

Toolbar

Add a type

Create a new type. The user will be prompted to enter a new name for the type, select its major and atomic type (where applicable), and whether it is a semi-structured type. It is then added to the type list at the left, and is now available for use anywhere within Nodose.

Delete a type

Delete the selected type. The type will be removed from the list at the left, and is no longer available for use within Nodose. The user is only able to delete a type if there are no existing nodes of that type, and it has no child types within the type hierarchy.

Change a type name

Edit the name of a type. The type will be modified in the list at left and throughout Nodose.

Change the major or atomic type

Change the major or atomic type of a type. The user is only able to change a type if it has no child types within the type hierarchy.

Create a new record field or list element

Add a field or element to a record or list. In the case of a list, the user will select the type of the elements. In the case of a record, the user will select the type of the field, enter a field name (or use the default) and mark whether the field is required.

Ancestor List

The ancestor list shows a list of all types that the currently selected type is an element of. The user can select any of the ancestor types, and that type will be selected in the type list.

Child List

The child list shows a list of all types that the currently selected type is the parent type of. This can be fields within a record, or elements within a list. The user can select any of the child types, and that type will be selected in the type list. The user can also add fields or elements to the currently selected type. In the case of a record, the user can also edit the field name or mark a field as required.

Statistics

The statistics sections shows a number of statistics, specific to the currently selected type and its associated instances. This allows the user to gain further information on a type, and look for anomylies or problems within their type system.
