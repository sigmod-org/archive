CCUBE Functionality

The functionality of the CCUBE system, depicted in the figure below, is a combination of the new CCUBE layer and ObjectStore OODBMS. Note that CCUBE as a virtual system (1) inherits "lower" features of ObjectStore, (2) replaces "middle" ObjectStore's features with those of the CCUBE layer, and (3) adds "upper'' features of the CCUBE layer. The CCUBE data manipulation language is an integration of a constraint calculus for extensible constraint domains and a hosting iterative language which is suitable for optimizing object-oriented queries. CCUBE queries are embedded in a C++ program and use data structures and classes defined in the program, subject to the C++ scoping rules. Thus, the basic object model of CCUBE is the one of C++. All CCUBE classes, such as for collections and constraints, are implemented as native C++ (template) classes.
