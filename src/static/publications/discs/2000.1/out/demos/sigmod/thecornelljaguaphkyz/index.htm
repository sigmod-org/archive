The CORNELL Jaguar Project: Adding Mobility to Predator


Philippe Bonnet, Kyle Buza, Zhiyuan Chen, Victor Cheng, Randolph Chung, Takako Jickey, Ryan Kennedy, Daniel Mahashin, Tobias Mayr, Ivan Oprencak, Praveen Seshadri, Hubert Siu

Computer Science Department
Cornell University
Ithaca, NY 14853

The CORNELL Jaguar project is exploring a variety of issues related to mobility and query processing. One broad theme is to break down the traditional client and server boundaries, leading to ubiquitous query processing. The project builds on and extends the CORNELL Predator database engine.

Our demonstration is composed of three compementary components (please click on the hyperlink associated to each demonstration component to view a powerpoint show summarizing its key features):
Server- and Client-site Extensions using Java: We demonstrate the ability to extend PREDATOR with user-defined functions written in Java and executed either on the server-site or on the client-site (here are the slides from the Sigmod'99 talk Client-site Query Extensions). Please contact Tobias Mayr for more information.
Result Compression for Clients: We demonstrate algorithms that compress query results utilizing the semantic information available in the query. Please contact Zhiuyan Chen for detailed information.
Device Databases: We demonstrate a data and system architecture that integrates devices (e.g. smartcards, sensors) with a regular object-relational database system. Please contact Philippe Bonnet for detailed information.
