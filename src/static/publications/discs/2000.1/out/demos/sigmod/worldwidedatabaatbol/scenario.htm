When you start the system, you are presented with the Royal Brisbane Hospital (RBH) database?s information space (i.e. coalitions and service links).

 

  1. Querying the Meta-Data
  • Click on the Medical coalition?s drop-down icon, and then click on the TheatreEquipment coalition?s drop-down icon

This will display two sub-coalitions of the coalition Medical.
  • Click on the Medical coalition

This will display the instances of the coalition, including those of the two sub-coalitions.
  • Click on the instance Royal_Brisbane_Hospital_Management_System

Notice that the right hand panel is now enabled and it has three different tabs. This does three functions:
    1. Display documentation types.
    2. Display attributes (characteristics) of the database.
    3. Display the exported schema of the database.
  • Click on any documentation types

This will display the documentation for the chosen documentation type.
  • Click on the TheatreEquipment and the SurgicalAppliances sub-coalitions

This will display those instances belonging only to those sub-coalitions
  • Use the Textual Query box and type: Display Instances Of Coalition Insurance, then press enter

This will display all instances of the coalition Insurance.
  • Click on the Coalition to Database service link type

This will display all service instances for that service link type.
  • On the Textual Query box, type: Display Attributes Of Instance Coalition_Insurance>Medicare_Database Service Coalition_ToDatabase

This will give you the attributes of Medicare_Database. Replacing Display Attributes with Display DocumentationTypes will give you the documentation types for the database.
  • Double-click on the service link Coalition_Insurance>Medicare_Database

This will direct you to the Medicare database.
  • Click on the Medicare_Database

This will show the SQL Query tab. You can click on the tab to look at the database schema and query it.

  • Click on the service link Medicare_Database>ATO_Database, and click on any documentation types

This will display the documentation of ATO_Database.

  • Use the Textual Query box to type: Follow Service Service_Database_ToDatabase:Medicare_Database>ATO_Database, and press enter

This will take you to the ATO database.
 
  1. Querying the Actual Data
  • Click on the ATO_Database instance or type in the Textual Query box: Display Interface Of Instance ATO_Database
  • Then click on the SQL Query tab on the most right panel, and type in the SQL Query text area: Select * from taxPayer
