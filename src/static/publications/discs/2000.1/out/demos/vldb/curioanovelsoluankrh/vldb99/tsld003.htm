Introduction

  • Characteristics of Data Warehouses:
    • Very large data sizes (e.g., Terabytes)
    • Complex, ad-hoc queries
    • Results delivered interactively
  • Two Key Issues:
    • Query performance
    • Storage requirements
  • Existing Approaches
    • Precomputation Strategies - answers to known queries are stored
    • Indexing Techniques - fast access to base data allows ad-hoc queries
