VLDB99 - Demonstration of the Miroweb project : mediator and client interface

Creating XMLQL queries via the browser

 

    The miroweb browser is decomposed into 3 parts :

  • The Control part which allows the user to chos the mode he is in :
    • making a request by viewing a tree
    • see the XMLQL request in litteral form
    • viewing the result in a tree form
    • viewing the XML result in a litteral form
  • The Where part where all constraint, joins and tables are shown or made
  • The construct part which allows the user to construct the final result, for example, he can restructurate all the different trees or modify the labels.
