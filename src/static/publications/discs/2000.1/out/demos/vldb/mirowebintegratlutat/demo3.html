Creating XMLQL queries via the browser

 The XML-QL query is written literally from the previous graphic query.

The XML-QL request is :
 
WHERE
<racine>
   <person>
       <first_name>$8</first_name>
       <last_name>$10</last_name>
       <birth_date>$11</birth_date>
       <contact>
            <address>
                <country>$12</country>
                <town>$14</town>
                <street>$15</street>
                <E-mail>$16</E-mail>
            </address>
       </contact>
    </person>
    <rapport>
         <categorie>$18</categorie>
         <annee>$20</annee> IN [$20 > 1990 AND $20 <= 1999]
         <langage>$21</langage>
         <titre>$22</titre>
         <auteur>
             <nom_de_famille>$23</nom_de_famille> IN[$8 = $23]
             <prenom>$25</prenom> IN [$10 = $25]
         </auteur>
    </rapport>		 CONSTRUCT
<result>
    <person>
        <first_name>$8</first_name>
        <last_name>$10</last_name>
        <birth_date>$11</birth_date>
        <contact>
            <address>
                <country>$12</country>
                <town>$14</town>
                <street>$15</street>
                <E-mail>$16</E-mail>
            </address>

         </contact>
         <publication>
             <title>$22</title>
             <category>$18</category>
         </publication>
    </person>
</result>
