CHANGING YOUR MIND

The second iteration manages to retrieve mainly faces from the database, including some male faces!

Notice that we do not have any face-recognition-specific tools used in this demo, which may explain the fruit platter popping up in the ranking.

Because the current implementation uses only a single step from the history, it is simple to change the query this way. Using more previous steps of the iteration may improve the value of relevance feedback within a session. But, it would make it more complicated to detect a change in the user's interest. As a solution, again we should simply ask users to tell us when their information need changes. Again, this illustrates the necessity of a proper dialogue between retrieval system and user, rather than the traditional one-step query-answer process.
