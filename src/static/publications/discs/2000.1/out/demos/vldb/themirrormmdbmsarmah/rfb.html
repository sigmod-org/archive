INITIAL QUERY

A text query on the annotations is the most obvious approach to search in multimedia databases. For example, let us search for images using a text query "ocean beach sea".

On the foreground, you see a user interface implemented using a standard Java IDE. Since all components in the Mirror architecture communicate with each other using CORBA, it is always possible to change the user interface without affecting the rest of the system. The three windows on the background will be invisible to the end user, but here they clearly illustrate the three levels (conceptual, logical, physical) of a DBMS architecture.
