PDF Search

This CD-ROM provides a full text index for those papers included in DiSC'00. The index is based on text extracted from the scanned paper images using optical character recognition (OCR) techniques. The accuracy of the text extraction process is limited in some cases by the quality of the original typescript; this can also affect the quality of text that can be selected using the Acrobat text selection tool.

You can utilize the full text index with Adobe Acrobat Reader 3.01+ With Search, which can be found under the install directory of the ACM SIGMOD Anthology, Volume 1, Issue 3, or online at Adobe's Acrobat Web Site. Once within Acrobat Reader, select tools/Search/Indexes from the menu, then Add. Select the file Disc00.pdx from the root directory of DiSC'00 CD#1.

To search for specific words of phrases, select Tools/Search/Query, and enter your keywords in the dialog box.

For additional information on performing full text searches, choose the Help/Plug-In Help/Using Acrobat Search menu entry for complete details.



Author Index

Also available on DiSC'00 is an index of all SIGMOD'99, PODS'99, and VLDB'99 authors, along with their contributions. The Author Index can be selected at any time from the menu to the left.
