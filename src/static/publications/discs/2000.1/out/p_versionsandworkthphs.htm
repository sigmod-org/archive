Versions and Workspaces in Microsoft Repository

Thomas Bergstraesser, Philip A. Bernstein, Shankar Pal, and David Shutt

  View Paper (PDF)     View Slides (HTML)  

Return to Industrial Session: E-Commerce and Repositories

Abstract
This paper describes the version and workspace features of Micro-soft Repository, a layer that implements fine-grained objects and relationships on top of Microsoft SQL Server. It supports branch-ing and merging of versions, delta storage, checkout-checkin, and single-version views for version-unaware applications.
