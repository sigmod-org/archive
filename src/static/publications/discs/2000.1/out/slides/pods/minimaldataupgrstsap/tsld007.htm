Classification Constraints

  • Basic constraints

    • Establish minimum levels for attributes
    • e.g., ?(Name) ? U; ?(Salary) ? C

  • Inference and association constraints

    • Protect against information leakage
    • e.g., lub(?(Name), ?(Salary)) ? S

  • Classification integrity constraints

    • Include primary key, referential integrity
    • e.g., ?(A) ? ?(B)
