As an added bonus...

  • Incomplete lattices

    • No top level (no universal visibility)
      • Approach:
        • Add dummy top level and run as before
        • If an object is labeled at top, no visibility
      • No bottom level (no unclassified data)
        • Approach:
          • Add dummy bottom level and run as before
          • If an object is labeled at bottom, there was no effective constraint on that object’s classification
