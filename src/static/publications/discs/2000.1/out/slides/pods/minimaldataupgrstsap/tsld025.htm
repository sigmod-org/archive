Summary

    • Linear (in constraints) for acyclic
    • Quadratic (worst-case) for cyclic
    • Hybrid algorithm for best performance
    • Works also with upper-bound constraints and incomplete lattices
    • NP-complete for nonlattices

  • Where do we go from here?

    • Element-level classification
    • Incremental updates
    • Solution tuning, “soft” upper bounds
