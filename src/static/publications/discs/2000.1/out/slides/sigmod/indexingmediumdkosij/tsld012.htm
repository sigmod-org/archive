Linear Quadtree

  • Index Creation

    • Tesselate geometries into quadtree tiles
    • Linearize the tiles by associating Peano codes
    • Index the tiles using a B-tree on the codes

  • Query

    • Tesselate query into quadtree tiles (start interface)
    • Identify geometry tiles that match query tiles using the B-tree index (fetch interface)
