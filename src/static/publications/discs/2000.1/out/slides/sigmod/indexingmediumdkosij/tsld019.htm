Index table

    Each row corresponds to an R-tree node:

  • array of <child_rowid, child_mbr>

    • child_rowid
      • in non-leaf nodes: refers to the child_node row in the same table
      • in leaf nodes: refers to the rowid of the data item in the data table

  • child_count, node_height

  • node_id, rowid of sibling node

  • rowid of root, root_node_id
