TimesTen: Familiar on the Outside

  • TimesTen IS an RDBMS

    • Relational Data Model (Tables, Indices, Joins…)
    • ANSI Standard SQL Interface
    • ODBC / JDBC APIs
    • Client/Server Ready

  • TimesTen IS Reliable, Durable, and Recoverable

    • Backup/Restore/Recovery/Bulk Copy/Replication
    • Adherence to “ACID” Properties (Atomicity, Consistency, Isolation, Durability)

  • TimesTen IS Highly Concurrent

    • Row-Level Locking
    • Multi-Threaded Applications Support

  • HP-UX, Solaris, AIX, NT, LynxOS
