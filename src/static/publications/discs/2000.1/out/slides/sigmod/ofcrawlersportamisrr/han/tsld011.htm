Question # 2: Can Web Structure Be Mined?

    • Yahoo!, AOL, and other information service providers are teachers (training sets) for Web page automatic classification
    • Classification leads to “lattices”, “trees”, or “clusters”

  • Mine patterns involving Web pages and hyperlinks?

    • Find authoritative Web pages
    • Find Web page structures and clusters.
    • Query and mine Web structures
