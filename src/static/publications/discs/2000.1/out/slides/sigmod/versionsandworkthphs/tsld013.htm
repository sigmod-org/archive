Object Version Merge

  • Compare versions with common ancestor and generate two change lists

  • If only one version changed a property, apply the change

  • If both versions changed a property, pick the ‘primary’ input

  • Merge collections item by item,

  • … or pick one of the two collections

    • E.g. steps of a task vs. author of a task

  • Override in a wrapper for custom merge
