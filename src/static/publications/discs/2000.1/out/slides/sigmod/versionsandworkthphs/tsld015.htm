Relationships

  • For power and flexibility

    • Store version-to-version relationships
    • Each relationship connects a source version to a set of target versions

  • For backward compatibility

    • Default resolution to latest target version

  • For efficiency use delta storage

    • Harder than properties, due to sequencing, bidirectionality, and pinning

  • For ease-of-use

    • CreateVersion optionally copies relationships
    • E.g. Task-Has-Step copies relationships but Task-LastUpdatedBy-User does not
