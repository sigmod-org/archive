Workspaces

  • Goal - support team development

    • Isolate users from each other
    • Users control when their changes are sharable
    • Long design-time ‘transactions’
    • Intuitive, V1 compatible, fast and efficient

  • Workspace is a virtual, private repository
    • Checkout/checkin repository-to-workspace
    • Workspace-scoped operations
    • Supports repository session interfaces
