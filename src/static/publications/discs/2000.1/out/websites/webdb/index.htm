GOALS

To provide a forum for researchers and practitioners on the interactions between database technology and database theory and the World Wide Web. This workshop is the second of a new series. The first WebDB workshop was held in Valencia, Spain in conjunction with the EDBT'98 conference. It was a great success both by the quality of its papers and its number of attendees. The proceedings were published by Springer Verlag, as part of the Lecture Notes in Computer Science (LNCS) series. This second issue of WebDB was as successful. We received 55 submissions of excellent quality out of which, due to time limitation, we accepted only 16.

Panel: How will we store large XML documents?

Moderated by Peter Buneman, the panel addressed the problem of storing large bodies of XML. The participants were:

  • George Feinberg (ODI)
  • Daniela Florescu (INRIA)
  • Muralidhar Krishnaprasad (Oracle)
  • Roy Goldman (Stanford University)
  • Michael Rys (Microsoft)
  • Dan Suciu (AT&T)
Here are some debating points.
1.
We don't need to do this. XML is a transport mechanism, not a data model. All we need to do is generate and digest structured XML and use conventional database systems for storage.
2.
XML can be cleanly represented in an OODBMS and the DOM API (the only universally accepted API for XML) is easy to implement. Therefore XML will be the savior of object-oriented database technology.
3.
We can adapt relational database technology to handle XML efficiently.
4.
We need new technology for this purpose.
