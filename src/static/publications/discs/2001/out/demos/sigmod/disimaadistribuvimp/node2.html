Modeling and Querying Images

In DISIMA, an image is composed of a set of physical salient objects (PSO) which are regions of this particular image with some syntactic features such as shape, color, and texture. The meaning of a PSO is given by a logical salient object (LSO), an abstraction of all the PSOs, referring to the same real world concept. More information on the model can be found in [OÖL97,OÖSI99,OÖIL99].
