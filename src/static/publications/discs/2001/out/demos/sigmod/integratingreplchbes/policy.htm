LRU Scheme

LRU - Least recently used.  It uses a global counter to assign priority value to a slot during assigning and updating of slot’s priority value when the slot is being accessed.  During replacement, the slot with the smallest priority value will be selected as the victim.

MRU Scheme

 

MRU – Most recently used.  The scheme is similar to the LRU Scheme.  Unlike LRU, MRU selected the slot with the largest priority value as victim.

LRD Scheme

 

LRD – Least Recent Density.  The scheme is derived from LFU (Least Frequently Used).  In LFU, the slot with the least frequently used is being selected as the victim.  In LRD, instead of just replacing the least frequently used slot, an aging of the slot is being introduced to the selection process. 

 

Frequent Count is the number of time the page is being accessed while it is in the buffer.  Reference Count is the time stamp in which is first accessed and Current Count is the value of the global counter at that specified time.

 

Priority Value of each slot is computed as followed.

 

If (Current Count – Reference Count > 0)

  Frequent Count / (Current Count – Reference Count)

Else

  0

The slot with the smallest priority value will be replaced.

 

LRU-2 Scheme

 

The LRU-2 algorithm uses the Backward 2-distance to decide the replacement page.  The Backward 2-distance is defined as follows.  Given a reference string known up to the time t, r(1), r(2), r(3), ......, r(t), the backward 2-distance B(t) (p,2) is the distance backward to the 2th most recent reference to the page p:

B(t) (p,2) = x if r(t-x) has the value of p and there have been exactly 1 other values i with t-x < i <= t where r(i) = p

Otherwise, B(t) (p,2) = infinity if p does not appear at least 1 time in r(1), r(2), r(3), ......, r(t)

 

The LRU-2 selects the replacement page whose backward 2-distance is the maximum of all pages in buffer. The only time the choice is ambiguous is when more than one page B(t) (p,2) = infinty. In this case, a subsidiary policy may be used to select the replacement victim among pages with infinite Backward 2-distance.

 

Level Random Scheme

 

The level random scheme is based on the B+ Tree Demo. The scheme will give higher priority over the internal node of the B+ Tree then the leaf node. When all the slots in the buffer are internal node of the B+ Tree, the scheme will randomly selected a replacement victim.

 

Level LRU Scheme

 

Exactly the same as the Level Random Scheme with the only exception of using a LRU scheme to select the replacement victim instead of selecting them randomly.
