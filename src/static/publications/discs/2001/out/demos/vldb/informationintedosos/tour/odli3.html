ODLI3 Language

ODLI3 extends ODL-ODMG with:
  • Intensional/terminological relationships between terms t(class and attribute names)
    • <t1 SYN t2 > (Synonymy)
    • <t1 BT t2 > (Broader Terms - BT)
    • <t1 NT t2 > (Narrower Terms - NT)
    • <t1 RT t2 > (Related Terms - RT)
  • Extensional Relationships between class names
    • <t1 SYNext t2 > the instance of C1 is the same of C2
    • <t1 BText t2 > the instance of C1 contains the instance of C2
    • <t1 NText t2 > the instance of C1 is contained into C2
  • Mapping rules (to represent relationships between the integrated schema and the schema of a source)
  • Union (to represent alternative data structures)
  • optional (*) (to represent optional attributes)
  • If then rules (to represent integrity coinstraints inter intra sources)
