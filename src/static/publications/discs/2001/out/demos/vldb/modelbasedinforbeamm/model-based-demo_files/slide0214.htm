Integration Issues: Mediating across
Multiple-Worlds
• Structural Integration
=> common semistructured data model (XML)
=> XML queries & transformations to resolve schema conflicts
• Limited Query Capabilities
=>  mediator is aware of QCs exported by wrappers
• ...
• Semantic Integration
– most work deals with issues for “one-world” scenarios
(e.g., amazon.com vs. bn.com)
– what if data comes from a “multiple-world” scenario (like
Neuroscience), where data objects from different sources
are not even similar, and only the hidden semantics (known
to the domain expert) provides the “semantic link”?
