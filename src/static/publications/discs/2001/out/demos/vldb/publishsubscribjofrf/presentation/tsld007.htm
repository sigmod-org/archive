Publication model (1)

  • Set of Attributes:

    • Its domain is : numeric, string, enumerated or hierarchical.
      Numeric: price, String : email
      Hierarchical : auction_category
    • It is single or multi-valued.
      Single: price, auction_category
      Multi-valued: email, description by keywords
