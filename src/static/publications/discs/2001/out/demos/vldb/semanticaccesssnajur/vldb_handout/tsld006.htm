Semantic Data Model(Sem-ODM) Benefits (Cont.)

    Semantic-Views

  • Data is described at conceptual level.

  • Meaning of Information is Stored

  • Relationships Between Categories

  • Easier to formulate query

    • Any Relationship CAN be queried.
    • Joins are NOT required to be defined explicitly.

    RDBMS

  • Data is described at logical level.

  • Meaning of Information is Lost

  • Relationships not Supported

  • Complex queries have to be pre-programmed

    • “Joins” are required to be defined explicitly.
