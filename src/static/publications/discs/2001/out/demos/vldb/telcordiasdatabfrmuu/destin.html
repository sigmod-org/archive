Destination

The Destination block is usually used at the end of a flow diagram. It has one input and no output. The selections for this block are the following.

SeqDataSave
RndDataSave

The selection of sequential or random depends on the type of input to which it is connected.

Properties, in the popup menu allows the user to select the file in which the data to be saved, View Data, in its popup menu displays the data, while Run when invoked saves the results.
