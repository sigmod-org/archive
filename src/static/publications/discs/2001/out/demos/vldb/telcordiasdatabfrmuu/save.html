Saving and Retrieving a Flow Diagram in XML

Saving a Flow Diagram

A flow diagram and the associated parameters can be saved in XML format. The XML representation of a flow diagram is very concise and can be also be textually modified before being loaded.  A flow diagram can be saved by selecting the menu item Save or Save As from the File menu, or the Save button in the tool bar. The XML file can also be edited to make any valid changes before being loaded.

Loading a Flow Diagram

Apart from interactively creating a flow diagram, one can also load it from a file, which was previously saved using this tool. This can be done by using the menu item Open from the File menu or the Open button in the tool bar.
