javax.XXL: A prototype for a Library of Query processing Algorithms


Jochen Van den Bercken, Jens-Peter Dittrich, and Bernhard Seeger

  View Paper (PDF)     View Demo (HTML)  

Return to Demonstrations


Abstract

In our demo we present XXL (eXtensible and fleXible Library), a toolkit for rapid prototyping of query processing algorithms. XXL is a flexible, easy-to-use, platform independent Java-library. It provides a powerful collection of generic index-structures, query operators and algorithms facilitating the performance evaluation of new query processing techniques. Query algorithms in XXL use the same set of basic classes like I/O routines and improved (de)serialization methods.
