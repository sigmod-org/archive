Os seguintes minicursos foram escolhidos para o SBBD'2000:

 
Título:  Integrando Banco de Dados e Web
Língua:  Português
Ministrante: Javam C. Machado, UFC
Resumo: Integração BD e WEB: Arquitetura de integração, Aspectos da integração, Manutenção do estado da aplicação. Arquiteturas de Integração: Acesso ao BD do Servidor WEB, Programas executáveis CGI, Gerenciador de aplicação, Aplicação API, Server Side Include, Acesso ao BD do cliente WEB, Aplicação externa, Cliente WEB estendido.
 
 
Título:  Data Warehouse: Estratégias, Arquitetura e Ferramentas
Língua:  Português
Ministrante: Maria Luíza Machado Campos, UFRJ
Resumo: O ambiente de dados para suporte aos processos de gerência e tomada de decisão é fundamentalmente diferente do ambiente convencional de processamento de transações. No coração deste ambiente está a idéia do Data Warehouse, integrando e consolidando dados disponíveis em diferentes acervos para fins de exploração e análise, ampliando o conteúdo informacional destes acervos para atender às expectativas e necessidades de nível estratégico na empresa. Este curso tem por objetivo apresentar o estado da arte da tecnologia de Data Warehouse, introduzindo os principais conceitos na área e discutindo as diferenças deste ambiente para os ambientes e ferramentas usuais de gerenciamento e tratamento de informações. Serão discutidas estratégias de implantação, aspectos do desenvolvimento e modelagem de bancos de dados em DW, funcionalidades e exemplo de ferramentas OLAP, e finalmente os fatores críticos de projetos nesta área.
 
 
Título:  Banco de Dados Orientado a Objetos
Língua:  Português
Ministrante: Marcus Sampaio, UFPB
Resumo: A organização, armazenamento, recuperação e atualização da informação, no ambiente global propiciado pela Internet, são realizados cada vez mais intensivamente pelos sistemas de gerência de banco de dados (SGBD). Como marcos da evolução das tecnologias de banco de dados, podemos citar: o modelo relacional, introduzido no limiar dos anos 70; linguagens, sistemas e bancos de dados orientados a objeto, aparecidos em meados da década de 80. Para atestar a importância da orientação a objeto (OO), os vendedores de SGBDs relacionais têm incorporado a noção de objeto em seus novos produtos, surgindo assim soluções híbridas objeto-relacionais (SGBD OR). Por outro lado, existem mais de dez fabricantes de SGBDs OO. Na primeira parte do curso, será discutida a proposta ODMG de padronização de SGBDs OO, como base para uma análise comparativa de SGBDs. A comparação envol-verá o SGBD OO Jasmine, e os SGBDs OR Oracle 8i e Informix Universal Server. Na se-gunda parte, uma solução OO completa será apresentada, utilizando "ao vivo" o SGBD Jasmine.
 
 
Título:  Integrando Java e Banco de Dados
Língua:  Português
Ministrante: Jorge Henrique Cabral Fernandes, UFRN
Resumo: Desde que foi criada em 1995, pela Sun Microsystems, a linguagem Java tem se firmado como solução viável no desenvolvimento de sistemas computacionais orientados a objetos. Um aspecto particularmnete importante para o desenvolvimento de sistemas de médio e grande porte com Java, é a integração entre bancos de dados relacionais SQL e programas na linguagem Java. A API padronizada que oferece este suporte entre Java e Bancos de Dados Relacionais é a JDBC. Este minicurso se propõe a mostrar para os iniciantes na linguagem Java quais são os aspectos fundamentais e alguns aspectos avançados do uso da API JDBC.
