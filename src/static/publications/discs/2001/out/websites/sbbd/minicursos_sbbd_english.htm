Títle:  Data Warehouse: Estratégias, Arquitetura e Ferramentas
Language:  Portuguese
Master: Maria Luíza Machado Campos, UFRJ
Abstract: The environment of data for bed to the management processes and taking of decision is basically different of the conventional environment of processing of transactions. In the heart of this environment it is the idea of the Data Warehouse , integrating and consolidating given available in different quantities for scanning ends and analysis, extending the information content of these quantities to take care of to the expectations and necessities of strategical level in the company. This course has for objective to present the state of the art of the technology of Data Warehouse, introducing the main concepts in the area and arguing the differences of this environment for the environments and usual tools of management and handling of information. Strategies of implantation, aspects of the development and modeling of data bases in DW will be argued, functionalities and example of tools OLAP, and finally the critical factors of designs in this area.
 
 
Títle:  Banco de Dados Orientado a Objetos
Language:  Portuguese
Master: Marcus Sampaio, UFPB

Abstract:

 

The organization, storage, backup and update of the information, in the global environment propitiated by the Internet, are carried through each time more intensively for the systems of management of data base (SMDB). As landmarks of the evolution of the technologies of data base, we can cite: the relationary model, introduced in the threshold of years 70; languages, systems and oriented object data base, appeared data bases in middle of the decade of 80. To certify the importance of the object oriented (OO), the relationary salesmen of SGBDs have incorporated the object notion in its new products, thus appearing object-relationary hybrid solutions (SGBD OR). On the other hand, ten manufacturers of SGBDs OO. In the first part of the course exist more than, will be argued proposal ODMG of standardization of OO SGBDs, as base for a comparative analysis of SGBDs. The matching will involve OO SGBD Jasmine, and SGBDs OR Oracle 8i and Universal Informix Server. In the second part, an OO full solution will be presented, using " to the living creature " the SGBD Jasmine.

 
 
Títle:  Integrando Banco de Dados e Java
Language:  Portuguese
Master: Jorge Henrique Cabral Fernandes, UFRN
Abstract: Since that it was created in 1995, for the Sun Microsystems, the Java language if has firmed as viable solution in the development of computational object oriented systems. An important aspect for the development of systems of medium and great size with Java, is the integration between relationary data bases SQL and programs in the Java language. The standardized API that offers to this bed between Java and Relationary Data bases is the JDBC. This minicourse if considers to show for beginning in the Java language which is the basic aspects and some advanced aspects of the use of API JDBC.
