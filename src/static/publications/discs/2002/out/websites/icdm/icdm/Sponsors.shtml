ICDM Sponsors


The IEEE International Conference on Data Mining (ICDM) is sponsored by:

  • IEEE Computer Society Technical Committee on Pattern Analysis and Machine Intelligence (TC-PAMI)
  • IEEE Computer Society Task Force on Virtual Intelligence (TFVI)

Also, ICDM seeks corporate sponsors each year. The conference offers a list of possible benefits for our corporate sponsors.
