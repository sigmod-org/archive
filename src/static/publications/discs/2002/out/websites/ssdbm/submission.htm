SSDBM 2001

Paper Submission Process

Please note that this process has been changed in order to use the CyberChair system from Twente University.  All papers should be submitted using the following steps.

  • The final deadline for submission is Monday, February 12, 2001. 
  • Papers should be approximately 5000 words in length, or equivalently about 8 to 10 pages in IEEE US Letter Format.  For information regarding IEEE format please visit this link:
    ftp.computer.org/pub/outgoing/cspress/proceedings/

This site has style guides for LaTex and MS Word.  Authors need not worry about Copyright forms until papers are accepted.

  • There is a two-phase process for paper submission. 
    Visit the URL, http://www.ssdbm.gmu.edu/none/

    On that page you will be able to test whether you can view the "browse" button via your browser.  Next you will be asked to follow the link to the submission pages.
  1. In Step 1, Abstract Submission, please fill out the form with the requested information such as contact person, affiliation, phones, email, paper title, abstract and keywords. 

    Please check at least one of the Main Topic areas to ensure that an e-mail confirmation will be sent to you.  Also please indicate if an author is a member of the Program Committee.

    When this form is submitted an e-mail message will be sent to the contact author, providing the login and password needed for step 2.

  2. In Step 2, Paper Submission, you provide your login and password as indicated in the previous e-mail.  You may then upload the actual paper in a number of different formats (Adobe PDF is preferred).  You will be asked to indicate the type and location of the file to be submitted. Once the file has been uploaded successfully, you will receive another e-mail confirming receipt of your submission. 
  3. Please retain the e-mails for your records.
